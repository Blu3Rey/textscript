---
title: Coin Change
inputs: coins, amount
split: train
tags: array, dynamic-programming
---
`coins` lists the coin values available, with as many of each coin as you
like, and `amount` is a non-negative integer. Return the smallest number of
coins whose values add up to exactly `amount`, or `-1` if no combination
does.

Example: for `coins = [1, 2, 5]` and `amount = 11` the answer is `3`.
