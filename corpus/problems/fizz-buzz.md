title: Fizz Buzz
inputs: n
split: train

Given a positive integer `n`, return a list of `n` strings, one for each
number from `1` to `n` in order. For a multiple of both 3 and 5 the string
is `"FizzBuzz"`, for any other multiple of 3 it is `"Fizz"`, for any other
multiple of 5 it is `"Buzz"`, and for every other number it is the number
written in decimal.

Example: for `n = 6` the answer is
`["1", "2", "Fizz", "4", "Buzz", "Fizz"]`.
