---
title: Kth Largest Element
inputs: nums, k
split: train
tags: array, heap
---
Given a list of integers `nums` and an integer `k` between `1` and
`len(nums)`, return the value that would be in position `k` if `nums` were
ordered from largest to smallest. Repeated values count separately, so this
is not the `k`-th largest distinct value.

Example: for `nums = [3, 2, 3, 1, 2, 4, 5, 5, 6]` and `k = 4`, the answer is
`4`.
