---
title: Product of Array Except Self
inputs: nums
split: train
tags: array, prefix-product
---
Given a list of integers `nums`, return a list of the same length whose
value at each position `i` is the product of every element of `nums`
except the one at position `i`. Don't use division.

Example: for `nums = [2, 3, 4, 5]` the answer is `[60, 40, 30, 24]`.
