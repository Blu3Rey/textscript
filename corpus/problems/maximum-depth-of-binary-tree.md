---
title: Maximum Depth of Binary Tree
inputs: root
split: train
tags: tree, recursion, breadth-first-search
---
You are given `root`, the root node of a binary tree, or `None` if the tree
is empty. Each node has a value `val` and two children, `left` and `right`,
either of which may be `None`. Return the depth of the tree: the number of
nodes on the longest path from the root down to a node with no children.
An empty tree has depth `0`.

Example: a root `3` with children `9` and `20`, where `20` has children
`15` and `7`, has depth `3`.
