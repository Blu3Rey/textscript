---
title: Valid Anagram
inputs: s, t
split: train
tags: string, hash-map, sorting
---
Given two strings `s` and `t`, return `True` if `t` is made of exactly the
same characters as `s`, each used the same number of times, possibly in a
different order. Otherwise return `False`.

Example: `s = "night"`, `t = "thing"` gives `True`; `s = "abc"`,
`t = "abd"` gives `False`.
