---
title: Binary Search
inputs: nums, target
split: train
tags: array, binary-search
---
`nums` is a list of distinct integers in increasing order. Return the
position of `target` in `nums`, or `-1` if `target` doesn't occur in it.

Example: for `nums = [-3, 0, 4, 9, 15]` and `target = 9` the answer is `3`;
for `target = 5` it is `-1`.
