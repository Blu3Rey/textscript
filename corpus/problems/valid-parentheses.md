The string `s` contains only the characters `(`, `)`, `[`, `]`, `{` and `}`.
Return `True` if every bracket that opens is closed by a bracket of the same
type, and brackets close in the right order. Otherwise return `False`.

Example: `"([]{})"` gives `True`; `"(]"` and `"(("` give `False`.
