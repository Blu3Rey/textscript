---
title: Move Zeroes
inputs: nums
split: train
tags: array, two-pointers, in-place
---
Given a list of integers `nums`, rearrange it in place so that every zero
ends up at the end, while the non-zero values keep their original relative
order. Nothing needs to be returned.

Example: `[4, 0, 5, 0, 0, 7]` becomes `[4, 5, 7, 0, 0, 0]`.
