---
title: First Unique Character
inputs: s
split: train
tags: string, hash-map, counting
---
Given a string `s`, return the index of the leftmost character that occurs
exactly once in `s`. If every character repeats, return `-1`.

Example: for `"bubble"` the answer is `1` (the `u`); for `"xyxy"` it is
`-1`.
