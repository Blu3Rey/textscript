---
title: Find Minimum in Rotated Sorted Array
inputs: nums
split: test
tags: array, binary-search
---
`nums` holds distinct integers that were sorted in increasing order and
then rotated: some number of elements (possibly none) were taken from the
front and moved, in order, to the back. Return the smallest value in
`nums`.

Example: for `nums = [5, 7, 9, 1, 3]` the answer is `1`.
