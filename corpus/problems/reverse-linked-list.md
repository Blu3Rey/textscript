---
title: Reverse Linked List
inputs: head
split: train
tags: linked-list
---
You are given `head`, the first node of a singly linked list. Each node has
a value `val` and a pointer `next` to the following node; the last node's
`next` is `None`, and an empty list is just `head = None`. Reverse the order
of the nodes and return the head of the reversed list.

Example: the list `1 -> 2 -> 3 -> None` becomes `3 -> 2 -> 1 -> None`, so
the answer is the node holding `3`.
